AETHERPLAY W3 V6.7 — RESPONSIVO UNIVERSAL

Esta atualização remove a limitação de largura exclusiva para Android e aplica layout adaptável para celulares, tablets, notebooks e monitores.

Como atualizar:
1. Faça backup da versão publicada.
2. Substitua os arquivos do site pelos arquivos desta pasta, preservando os arquivos de configuração Firebase já validados.
3. Publique index.html, admin.html, css/, js/, assets/ e manifest.webmanifest.
4. Faça recarga forçada/limpe o cache do navegador se o CSS antigo continuar aparecendo.

Importante: esta atualização é visual/responsiva. Não altera regras do Firebase, saldos, recompensas ou permissões administrativas.
